FREELANCE AI — стартовый Telegram-бот для поиска заказов на оформление карточек товаров

Что умеет:
- проверяет подключённые RSS-ленты каждые 15 минут (интервал можно изменить);
- ищет объявления про карточки товаров, инфографику и дизайн листингов;
- при наличии OPENAI_API_KEY просит ИИ оценить релевантность;
- присылает подходящие объявления только владельцу;
- не отправляет отклики за вас;
- сохраняет уже просмотренные объявления в SQLite, чтобы не дублировать их.

ВАЖНО:
Это рабочая основа, но не универсальный поисковик по всем сайтам мира. Бот может искать только в источниках, которые вы подключите. Многие биржи не дают открытый RSS/API; для них может потребоваться официальная интеграция, ключ API или ручное добавление ленты. Соблюдайте правила сайтов. ИИ может ошибаться, проверяйте заказ и ссылку самостоятельно.

Установка (Windows):
1. Установите Python 3.11 или новее.
2. Распакуйте архив в отдельную папку.
3. Скопируйте .env.example в .env.
4. Впишите токен Telegram-бота в TELEGRAM_BOT_TOKEN.
5. Запустите бота и отправьте ему /myid. Впишите полученный номер в OWNER_TELEGRAM_ID в .env и перезапустите.
6. (Необязательно) Добавьте ключ API OpenAI в OPENAI_API_KEY. Без него будет работать простой фильтр по ключевым словам.
7. Добавьте RSS-ссылки в feeds.txt — по одной на строку.
8. Откройте терминал в папке проекта и выполните:
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python bot.py

На Linux/macOS вместо команды активации используйте:
   source .venv/bin/activate

Команды в Telegram:
/start — справка
/myid — показать ваш Telegram ID
/status — состояние бота
/sources — подключённые RSS-источники
/scan — запустить проверку вручную

Безопасность:
- Не публикуйте .env и никому не отправляйте токен бота или ключ OpenAI.
- Если токен Telegram случайно раскрыт, перевыпустите его через BotFather.
- Для работы 24/7 бот должен быть запущен на компьютере, который не выключается, или на сервере/VPS.
